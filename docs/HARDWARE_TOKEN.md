# Core Vault 9.0.1 物理硬件锁使用与技术指南 (Hardware Token Guide)

Core Vault 9.0.1 引入了基于 Windows 物理存储介质的硬件钥匙（Hardware Token）绑定技术，实现了“物理硬件在场才允许解密”的安全闭环。

---

## 💡 核心设计理念

传统的加解密软件仅依赖密码或数字密钥文件，一旦密码泄露或密钥文件被复制，数据将彻底失守。
Core Vault 硬件锁将**特定物理存储设备（U 盘、移动机械硬盘、移动固态 SSD）的只读硬件卷序列号**深度绑定至加密文件：
1. **加密绑定**：将待加密的文件与当前插入的物理设备锁死；
2. **解密物理阻断**：换到任何电脑上解密时，**必须插着绑定的这只硬件设备**；若未插入（或插错其他设备），系统直接抛出物理阻断警报，解密终止。

---

## 🔌 设备支持范围

Core Vault 9.0.1 突破了传统仅支持可移动 U 盘的限制：
* **传统 U 盘**：Windows 识别为 `DRIVE_REMOVABLE`（可移动磁盘）；
* **USB 移动硬盘 / 移动固态 SSD**：通过 Windows 底层 `IOCTL_STORAGE_QUERY_PROPERTY` 查询总线类型（`BusTypeUsb = 0x07`），即便系统标识为 `DRIVE_FIXED`（本地固定硬盘）也能精准识别；
* **跨接口与跨盘符识别**：以设备的硬件卷序列号（Volume Serial Number）为唯一标识。即使 U 盘插入不同 USB 口导致盘符（如从 `E:` 变为 `F:`）发生变化，只要设备一致均能瞬间识别并放行。

---

## 🚀 操作步骤

### 1. 绑定硬件钥匙
1. 将您的 U 盘或移动硬盘插入电脑；
2. 在 Core Vault 主界面右侧的“执行策略与并发”栏目中，点击 **`[🔑 硬件锁: 未绑定]`** 按钮（或进入“设置”页面）；
3. 在弹出的设备列表中，选择您的 U 盘或移动硬盘（如 `[E:\] 金士顿 [U盘 / 可移动磁盘] (序列号: 1A2B3C4D)`）；
4. 点击 **“确认绑定”**，状态按钮将变为绿色的 `🔑 硬件锁: 已就绪 (盘符 卷标)`。

### 2. 执行加密
* 拖入需要加密的文件或文件夹；
* 点击 **“立即开始处理”**；
* 生成的 `.enc` 文件将自动带有 `SAHW\x01` 硬件指纹容器，且派生密钥融合了硬件因子。

### 3. 执行解密
* 将加密文件拖入解密工作台；
* **测试拔出设备**：点击解密，系统直接弹出红色警告并阻断：
  > `【硬件锁拦截】该文件已物理绑定硬件钥匙设备 (序列号: XXXXXXXX)，当前电脑未插入该 U 盘 / 移动硬盘，解密被物理拒绝！`
* **插上绑定的设备**：点击解密，系统即刻校验通过并顺利解密出原文件。

---

## 🛡️ 安全特性总结

* **防拔出保护**：加解密执行期间，后台心跳每秒校验设备状态，若硬件被意外或强行拔出，流水线立即刹车并写零销毁内存中的密钥。
* **密码学级不可剥离**：硬件卷序列号不仅作为明文比对依据，更作为 HKDF 的 Salt / Info 参与派生。即使通过 Hex 编辑器将文件开头的硬件锁容器头强行删除，解密依然会因密钥不匹配直接失败。
