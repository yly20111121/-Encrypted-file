# 历史版本归档与技术演进 (Legacy Releases Archive)

本目录完整归档了项目从诞生至今的所有历史版本单文件与模块化代码，供技术回溯、协议研究与向下兼容性测试参考。

---

| :--- | :--- | :--- | :--- |

## 🔒 兼容性保证 (Backward Compatibility)
项目根目录中的最新版 **Core Vault 9.0.1** 内置全向后兼容引擎：
- 能够**原生、无缝**解密本目录下由任何历史版本（从 0.0.1 到 8.0.1）所加密生成的文件。
- 历史文件由于没有物理硬件锁标记，在 9.0.1 中解密时无需插入任何硬件钥匙，输入原始口令即可瞬间还原。
